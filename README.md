# Blinkit-Dashboard-Power-bI

1. Project Title / Headline
A concise, descriptive name for the dashboard.
Example: Blinkit: Blinkit Insights Dashboard A dynamic, interactive data visualization tool built to explore Blinkit data. 

3. Short Description / Purpose
1–2 sentences explaining what the dashboard does and why it exists.

Example: The Blinkit Dashboard is a visually engaging and analytical Power BI report designed to help users explore and compare a Total sales or total items. 

3. Tech Stack
List the key technologies used to build the dashboard.

Example: The dashboard was built using the following tools and technologies:
_ Power BI Desktop – Data visualization and dashboard development
_ DAX (Data Analysis Expressions) – Creating measures and calculated fields
_ Power Query (M Language) – Data cleaning and transformation
_ Microsoft Excel – Used as the data source (CSV/Excel format

4. Data Source
_ The dataset is sourced from Microsoft Excel (.xlsx), containing sales records for various outlet types, item categories, fat content, and ratings.
_ It includes fields like Item Type, Outlet Type, Sales, Item Visibility, Outlet Size, and Establishment Year.
_ Data was cleaned and transformed using Power Query before visualization.

5. Features / Highlights
Fully Interactive Dashboard: Filter by outlet size, location tier, item type, and fat content to get focused insights.

_ Sales Trend Over Time: Line and bar charts show sales trends from 2012 to 2022.
_ Outlet Analysis: Compare performance across outlet types (Grocery Store, Supermarket) and size (Small, Medium, High).
_ Item-Level Insights: Visual breakdown of sales by item category – Dairy, Household, Fruits, Vegetables, etc.
_ Ratings Analysis: Compare average product ratings and visibility by category.
_ Location-Based Filtering: Easily view how sales and performance vary across Tier 1, 2, and 3 cities.
_ KPI Cards: Instantly view Total Sales, Average Sales, Number of Items, and Average Ratings at a glance.
_ Dynamic Visuals: All charts and cards update instantly based on selected filters.
_ Cleaned & Transformed Data: Using Power Query for preprocessing, missing value handling, and data shaping.
